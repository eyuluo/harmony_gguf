UI 信息架构与交互规格
1. 总览
系统 UI 主要分为两大部分：
对话页面
后端服务页面
另有独立页面：
模型注册表页面
导航中的“模型”页即 模型注册表页面。
手机端与 PC 端导航顺序一致，仅位置不同：
手机端：导航栏在底部，从左往右：对话、模型、服务
PC 端：导航栏在左侧，从上往下：对话、模型、服务
对话页与服务页共享同一个“当前加载模型”。
2. 全局模型状态与规则
2.1 当前模型
对话页和服务页共享同一个“当前加载模型”。
从对话页或服务页点击“模型选择”，跳转到模型注册表页面。
在模型注册表页面加载模型成功后，自动返回原页面。
加载失败时，显示：“加载失败，请重新加载”。
2.2 加载模型流程
点击“加载模型”后：
跳出 参数配置页面 / 弹窗；
在参数配置中设置加载参数；
提供两个虚拟按键：
取消加载
确认加载
参数配置内容见 API；
点击“取消加载”：关闭配置页面 / 弹窗，不加载模型；
点击“确认加载”：按当前配置加载模型；
加载过程中显示模型加载过渡页面，展示模型信息 / 配置；
加载成功后自动返回原页面；
加载失败显示：“加载失败，请重新加载”。
2.3 已加载模型
模型加载完成后，该模型注册表项中的“加载模型”按钮不可点击。
该按钮改为：“停止模型”。
点击“停止模型”后：
停止所有对话和服务；
即使正在推理，也会中断；
当前模型置空；
对话页回到“未选择模型”状态；
服务页回到“未选择模型”状态。
2.4 参数详情弹窗
对话页与服务页共享同一个参数详情弹窗。
页面左上角提供“参数详情”入口。
弹窗显示：
当前加载的模型参数；
加载时配置的参数。
未加载模型时，该入口隐藏或不可用。
停止模型后，参数详情内容清空。
2.5 删除注册表前置条件
删除模型注册表项之前，必须满足：
已停止服务；
已停止对话；
已停止模型，即模型处于未加载状态。
删除注册表时：
需要二次确认；
提示文案：“仅删除注册表项，不会删除本地文件”；
提供确认 / 取消按钮。
3. 对话页面
3.1 未选择模型
显示模型选择入口。
点击后跳转到模型注册表页面。
3.2 模型加载过渡
展示模型信息 / 配置。
加载成功后自动返回原页面。
加载失败显示：“加载失败，请重新加载”。
3.3 已选择模型
页面包含：
对话列表；
对话框；
信息展示区域。
右上角统计信息显示最后一条已完成推理的：
输入 token；
输出 token；
首 token 延迟，ttft；
token 生成速率，tps。
如果新输入了信息并且正在推理：
显示：“推理中”；
不显示未完成请求的统计结果。
3.4 参数详情
页面左上角提供“参数详情”入口。
点击后打开与服务页共享的参数详情弹窗。
显示当前加载模型参数和加载时配置的参数。
3.5 状态流转
未选择模型 → 点击模型选择 → 模型注册表页；
模型注册表页配置参数并加载成功 → 自动返回对话页；
已选择模型 → 正常对话；
正在推理 → 显示“推理中”；
模型停止 → 回到未选择模型状态。
4. 服务页面
4.1 未选择模型
显示模型选择虚拟按键。
点击后跳转到模型注册表页面。
4.2 模型加载过渡
展示模型信息 / 配置。
加载成功后自动返回原页面。
加载失败显示：“加载失败，请重新加载”。
4.3 已加载模型状态
页面包含：
状态展示；
每分钟自动调用相关 API 进行检测；
启停按键；
服务调用列表。
状态展示
展示当前服务状态。
每分钟自动调用相关 API 检测。
具体检测 API 暂略。
健康检查默认不计入业务调用统计。
启停按键
只控制 API 服务启停；
不影响模型加载状态；
模型可以保持已加载，但服务停止。
服务调用列表
按调用来源分别展示。
每个调用来源包含：
调用方式；
调用来源：API 调用方端口，不是 serve 端口；
总输入 token；
总输出 token；
最后一条消息的：
输入 token；
输出 token；
ttft；
tps。
说明：
“最后一条消息”统计按各自来源分别计算；
不是全局最后一条。
4.4 统计持久化
服务调用统计采用相对持久化：
后端进程运行期间保留；
前端刷新页面不清空，重新从后端拉取当前统计；
后端进程重启后清空；
健康检查默认不计入业务调用统计。
4.5 参数详情
页面左上角提供“参数详情”入口。
点击后打开与对话页共享的参数详情弹窗。
显示当前加载模型参数和加载时配置的参数。
4.6 状态流转
未选择模型 → 点击模型选择 → 模型注册表页；
模型注册表页配置参数并加载成功 → 自动返回服务页；
已加载模型 → 可启动 / 停止 API 服务；
停止模型 → 当前模型置空，服务页回到未选择模型状态。
5. 模型注册表页面
模型注册表页面即导航中的“模型”页。
5.1 顶部操作
上方居中显示：导入模型虚拟按键。
右上方显示：删除不存在模型注册表虚拟按键。
5.2 模型导入与注册表生成
导入模型方式：选择文件。
选择文件时生成模型注册表项。
记录所选文件路径作为模型位置。
后续每次启动时，按照模型位置自动检测模型是否存在。
5.3 自动检测
每次启动时，按照模型位置自动检测模型是否存在。
模型存在：正常展示模型信息。
模型不存在：展示异常状态。
5.4 模型存在时展示信息
模型存在时展示：
本地模型名字；
模型位置；
模型架构；
模型参数量；
量化等级；
输入类型等参数。
操作按钮：
加载模型；
删除注册表。
加载模型
点击“加载模型”后：
跳出参数配置页面 / 弹窗；
参数配置内容见 API；
提供：
取消加载；
确认加载；
取消加载：关闭，不加载；
确认加载：按配置加载模型；
加载成功后自动返回原页面；
加载失败显示“加载失败，请重新加载”；
已加载后，加载按钮不可点击，改为“停止模型”。
删除注册表
删除注册表时：
提示：“仅删除注册表项，不会删除本地文件”；
提供确认 / 取消删除虚拟按键；
需要二次确认；
删除前必须已停止服务、停止对话、停止模型。
5.5 模型不存在时展示
模型不存在时：
名字与模型位置正常显示；
不显示其余信息；
用红色加粗文字替换：“未在该位置找到该模型”。
5.6 已加载模型状态
加载完成后，模型加载项不可点击；
被加载的模型按钮改为：“停止模型”；
点击“停止模型”：
停止所有对话和服务；
即使正在推理也会中断；
当前模型置空；
对话页和服务页回到未选择模型状态。
5.7 删除不存在模型注册表
位于右上角；
批量删除所有不存在项；
需要二次确认；
仅删除注册表项，不删除本地文件。

7. 关键交互规则汇总
“模型”页 = 模型注册表页面。
对话页和服务页共享同一个当前加载模型。
从对话页 / 服务页选择模型，跳转模型注册表页。
点击“加载模型”后，先弹出参数配置页面 / 弹窗。
参数配置包含取消加载、确认加载两个虚拟按键。
参数配置内容见 API。
确认加载后进入加载过渡，加载成功后自动返回原页面。
加载失败显示“加载失败，请重新加载”。
已加载模型按钮变为“停止模型”。
停止模型会停止所有对话和服务，即使正在推理。
停止模型后当前模型置空，对话页 / 服务页回到未选择模型状态。
对话页与服务页左上角共享同一个参数详情弹窗。
参数详情弹窗显示当前加载模型参数和加载时配置的参数。
服务页启停按键只控制 API 服务，不影响模型加载状态。
删除注册表前必须停止服务、停止对话、停止模型。
删除注册表需二次确认，仅删除注册表项，不删除本地文件。
导入模型通过选择文件完成，选择文件时生成注册表项。
每次启动按模型位置自动检测模型是否存在。
模型不存在时显示红色加粗“未在该位置找到该模型”。
对话统计显示最后一条已完成推理的输入 token、输出 token、ttft、tps。
对话正在推理时显示“推理中”。
服务调用列表按来源分别统计。
每个来源显示调用方式、来源端口、总输入 / 输出 token、最后一条消息的输入 / 输出 / ttft / tps。
服务统计在后端进程运行期间保留，前端刷新不清空，后端重启后清空。
健康检查默认不计入业务调用统计。
